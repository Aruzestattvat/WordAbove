## WordAbove · 词在上 1.1.2

本版专门修复用户反馈的 **「语言包安装很慢、经常失败」**。原因是首次准备实际是 **约 0.9 GB** 的系统级下载（解压后约 1.7 GB），而旧版没有进度、没有超时、关闭窗口会静默取消，失败信息也无法指导处理。1.1.2 把这段流程重做。

### 主要修复

- **关闭窗口/退出不再静默取消**：准备中关窗或退出会先确认，可继续准备；已验证的方向写入本地，重开应用仍显示「已就绪 N/6」。
- **不再无限等待**：每个方向最多等待 45 分钟，超时给出明确提示（不会删除系统已下载的资产）。
- **失败可归因**：按「网络 / 磁盘空间 / 系统翻译服务 / 超时」分类，并给出下一步建议；面板显示原始错误，可一键「复制诊断信息」。
- **进度看得见**：显示当前方向、已用时间、6 个方向的逐项状态；等待超过 3/10 分钟会提示可能的原因。
- **直达系统进度**：新增「打开语言设置」，打开 `系统设置 → 通用 → 语言和地区 → 翻译语言`，查看系统级下载状态。
- **磁盘预检**：开始前检查可用空间，低于 3 GB 直接提示，避免下载到一半失败。
- **修复进度文字在非主线程更新**的问题（可能导致进度不刷新/卡住）。

### 首次安装 / 升级

1. 下载 `WordAbove-1.1.2-macos-arm64.zip`，**用 Finder 双击解压**（命令行 `unzip` 可能因 `._*` 文件破坏签名），把 `词在上.app` 拖进 `/Applications` 覆盖旧版。
2. 打开应用 → 菜单栏 →「下载中英日语言包…」→「一键准备中英日」。
3. **首次下载约 0.9 GB，慢网可能需要 10–30 分钟**；请保持窗口打开，若系统弹出下载确认请点「允许」。
4. 显示「中英日已就绪 · 6/6」即可使用。**「N/6」是已验方向数，不是下载百分比**；系统不提供进度接口。

> 升级后如卡片不再出现，请重新授权辅助功能：
> `tccutil reset Accessibility local.wordabove.SpotlightDictionary`，再从「应用程序」打开并授权。
> **不要**替其他应用重置权限。

### 下载慢/失败时

- 换稳定网络；若在用 VPN / 代理，尝试关闭或改为全局模式。
- 至少保留 3 GB 磁盘空间。
- 到系统设置 → 通用 → 语言和地区 → 翻译语言 查看系统级下载进度（应用面板内有直达按钮）。
- 失败后点「重试未完成部分」，已验证方向不会重来。
- 仍失败时点「复制诊断信息」，把内容附在反馈里。

### 系统要求

| 功能 | 最低系统 |
|---|---|
| 自动翻译（中/英/日） | **macOS 26.0** |
| 离线英文词典 / 音标 / 例句 | macOS 14.0 |

- **Apple Silicon（arm64）**，本 Release 不提供 Intel 版本。
- 语言包由 macOS 管理并在本机运行；本仓库**不包含也不分发** Apple 翻译模型。

### 从源码构建

```bash
git clone https://github.com/Aruzestattvat/WordAbove.git
cd WordAbove
bash Scripts/build.sh --out dist --self-test
```

### 校验下载

```bash
shasum -a 256 -c WordAbove-1.1.2-macos-arm64.zip.sha256
```
