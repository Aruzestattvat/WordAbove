## WordAbove · 词在上 1.1.1

**从「英文词典」升级为「中英日本机互译」**：现在可以把任意中/英/日短词短句译成另一种语言，全部在设备上完成（Apple `Translation.framework`），不经过任何第三方翻译服务。英文单词命中离线词库时，仍显示中文释义、音标与例句。

### 下载与安装

1. 下载下面的 `WordAbove-1.1.1-macos-arm64.zip`
2. **用 Finder 双击解压**（不要用命令行 `unzip`，否则 `._*` 文件可能破坏签名）
3. 把 `词在上.app` 拖进 `/Applications`
4. 打开应用 → 在设置中点「打开辅助功能设置」→ 在**系统设置 → 隐私与安全性 → 辅助功能**里打开「词在上」
5. 菜单栏图标 →「下载中英日语言包…」→「一键准备中英日」，等它显示 **中英日已就绪 · 6/6**
6. 回到 Spotlight 输入 `你好` 或 `Hello`（无需回车）

> 首次打开若被拦下：**系统设置 → 隐私与安全性 → 仍要打开**。本包为本机临时签名，未经 Apple 公证。

### 本次新增

- **自动互译**：中文 ⇄ 英文（默认）、中文 ⇄ 日文、英文 ⇄ 日文；自动判断方向，也可固定正向/反向
- **一键准备中英日**：自动检查并下载缺少的语言包，再验证全部六个翻译方向；支持重试、取消、继续
- 支持短词与短句，最多 **400 字符**；语言对与方向保存在本机，重启后恢复
- 中日同形字处理：仅含汉字的词在中文/日文对下默认按中文处理；含假名按日文；可手动固定方向
- 新增 5 个源码文件：`TranslationSupport` / `TranslationCard` / `LanguageSetupView` / `LanguagePreparation` / `TranslationChecks`
- 卡片显示原文、语言方向与译文；不会为翻译结果编造音标或例句

### 系统要求（重要）

| 功能 | 最低系统 |
|---|---|
| 自动翻译（中/英/日） | **macOS 26.0** |
| 离线英文词典 / 音标 / 例句 | macOS 14.0 |
| 从源码构建 | macOS 26+ SDK（需含 `Translation.framework`）+ 匹配的 Swift 编译器 |

- **Apple Silicon（arm64）**，本 Release 不提供 Intel 版本
- 语言包由 macOS 管理，下载需要联网；下载后翻译在本机完成。本仓库**不包含也不分发** Apple 翻译模型
- 在 macOS 14/15 上离线英文查词仍可用，但翻译功能会提示需要升级系统

### 隐私

辅助功能仅用于读取 Spotlight 搜索栏与窗口位置；不记录键盘、不读取其他应用文本、不录屏、不保存搜索历史。
邮箱、网址、路径、纯数字、控制字符和超过 400 字符的输入不触发翻译。译文仅在内存缓存最近 100 条，退出清除。
英文词典的「缺少例句时联网补充」是独立可选项（默认开启，可在设置关闭），只把当前英文单词发给
`api.dictionaryapi.dev`，不影响 Apple 本机翻译。

### 从源码构建

```bash
git clone https://github.com/Aruzestattvat/WordAbove.git
cd WordAbove
bash Scripts/build.sh --out dist --self-test
```

离线词库与全部第三方许可已随仓库提供，**无需额外下载数据**。构建脚本自动探测可用 SDK，
也可用 `SDK_PATH=/路径/MacOSX.sdk` 指定；`ARCHS`、`MACOS_TARGET`、`CODESIGN` 等可覆盖。

### 已知问题

- 更新本地临时签名的版本后，可能需要重新授权辅助功能。若开关已开仍无卡片：
  `tccutil reset Accessibility local.wordabove.SpotlightDictionary`，然后从应用程序目录重新打开并授权。
  **不要**替其他应用重置权限。
- 卡片联动依赖辅助功能接口与窗口元数据，macOS 后续更新可能影响兼容性。
- 首次下载语言包时 macOS 可能分次弹出确认，请允许；系统已安装的语言包会复用。
