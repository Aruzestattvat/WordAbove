# WordAbove · 词在上 1.1.18 — macOS 27 优化

本版继续适配 macOS 27 的 Spotlight。**macOS 26 优化版 [v1.1.2](https://github.com/Aruzestattvat/WordAbove/releases/tag/v1.1.2) 继续保留**；两个版本都可以下载。

## 更新内容

- 点击词卡左侧的词典图标，一键复制首条中文释义；中英日系统翻译卡片则复制当前译文。复制后以原有单色风格显示圆内多重幻影圆环，沿不同轴旋转后收束为勾号，不抢走 Spotlight 的输入焦点；开启“减少动态效果”时直接显示勾号。
- 释义过长时可点击“完整释义”在卡片内展开、滚动查看，单词标题保持原位。
- 卡片按当前 Spotlight 外框和屏幕可用空间定位，适配 13、14、16 寸内屏、显示缩放和外接屏。窗口尺寸稳定变化后会重新对齐；每次重新打开都重新计算，不沿用旧尺寸。
- 顶部空间不足时缩到 64 pt，优先保留单词与释义。空间小于 64 pt 时隐藏，仍只显示在 Spotlight 上方。
- 修复快速输入时卡片与搜索框短暂重叠，以及关闭 Spotlight 后词卡单独闪现。Esc 保持 macOS 原有行为。
- 保留随系统 Liquid Glass 设置变化的原生玻璃效果、离线词库与中英日六方向本机翻译。
- 精简菜单栏：常用语言和暂停操作留在主菜单，语言包、预览和诊断移到“更多”。
- 新增检查更新和一键安装：本版起会定期检查 GitHub 正式版，发现新版时提示安装；下载包会校验 GitHub 提供的 SHA-256 和应用签名。

## 安装

下载下方 `WordAbove-1.1.18-macos-arm64.zip`，用 Finder 解压并将「词在上.app」拖到“应用程序”覆盖旧版，然后重新打开。若更新后卡片不出现，请在“系统设置 → 隐私与安全性 → 辅助功能”重新授权当前安装版。

安装包适用于 Apple Silicon，采用临时签名，未经 Apple 公证。自动翻译需要 macOS 26 或更新版本；英文离线词典支持 macOS 14 或更新版本。中英日翻译语言包由 macOS 下载和管理，不随安装包分发。

**旧版需要手动升级一次。** 1.1.10 及更早版本没有内置更新器，无法远程向这些已安装设备推送安装提示。安装 1.1.18 后，后续版本会在应用内提示并提供一键安装；临时签名更新后，macOS 仍可能要求重新授权辅助功能。更新检查会连接 GitHub，不上传搜索词或翻译内容。

下载后可用随附的校验文件检查：

```sh
shasum -a 256 -c WordAbove-1.1.18-macos-arm64.zip.sha256
```
